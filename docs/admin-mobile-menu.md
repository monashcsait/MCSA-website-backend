# 后台视觉与手机菜单改动说明

日期：2026-10-02

功能分支：`admin-mobile-menu`

## 这次改了什么

此分支包含此前的后台视觉／手机布局提交 `e42185b`，以及可收起菜单提交 `41415bb`。

- 统一后台按钮、表单、卡片、间距和提示样式。
- 手机端保留可见的保存、预览、备份和退出操作栏。
- 手机竖屏及较矮的手机横屏窗口中，栏目列表默认收起；点“☰ 栏目”后打开左侧菜单，选择栏目后回到编辑区。
- 菜单支持关闭按钮、点击遮罩、Esc 关闭，及 Tab 焦点循环；切回桌面时关闭菜单并恢复背景滚动。
- 桌面继续显示原有侧边栏目列表。

原有 15 个栏目的名称、标识和顺序保持不变，没有增删栏目或改变内容数据结构。
